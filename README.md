# Учёт личных расходов студента

Прототип для учёта личных расходов: добавление трат с суммой, категорией
и датой, просмотр списка и итогов за выбранный месяц. Реализовано без ИИ
и без внешних API — расчёты выполняются полностью на введённых
пользователем данных.

## Запуск

Приложение представляет собой статическую страницу (HTML/CSS/JS без
сборки и зависимостей). Достаточно открыть `index.html` в браузере,
либо поднять любой статический сервер из корня проекта, например:

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000` в браузере.

## Реализованные функции

- Форма добавления расхода: сумма (обязательна, положительное число),
  категория (обязательна, выбор из списка), дата (обязательна), описание
  (необязательно). Некорректный ввод отклоняется с понятным сообщением
  об ошибке.
- Список расходов за выбранный месяц с возможностью удаления записи.
- Общий итог и суммы по категориям, которые пересчитываются при
  добавлении, удалении расхода и при смене месяца. Сумма по категориям
  всегда равна общему итогу.
- Переключатель месяца для просмотра расходов и итогов за нужный период.
- Хранение данных в `localStorage` браузера — записи остаются после
  обновления страницы.
- Единая валюта без конвертации; пустой список отображается отдельным
  состоянием ("Расходов за этот месяц пока нет").

## Проверочный пример

Для одного месяца добавляются три расхода: еда — 1500, транспорт — 600,
еда — 900.

- Ожидаемый результат: общий итог 3000, еда — 2400, транспорт — 600.
- После удаления расхода на 900: общий итог — 2100, еда — 1500.

## Ограничения

Обязательный сценарий не включает регистрацию, синхронизацию между
устройствами, банковские интеграции и реальные платежи — хранения
данных в браузере достаточно для прототипа. Реализация в виде Telegram
Mini App в этом репозитории не включена.

## Структура проекта

- `index.html` — разметка страницы (форма, список, итоги).
- `style.css` — стили интерфейса.
- `app.js` — логика: валидация, хранение в `localStorage`, расчёт
  итогов, рендеринг списка и удаление записей.
